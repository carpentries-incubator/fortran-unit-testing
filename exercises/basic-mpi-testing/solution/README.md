## Task

In [test](./test) there are some pFUnit tests.

Write MPI enabled pFUnit tests for the each function in the `mpi_utils` library.

1. Write tests for `sum_all_rank_values` with MPI-enabled pFUnit.
2. Write tests for `sum_preceding_rank_values` with MPI-enabled pFUnit.

## Task 1

> Write tests for `sum_all_rank_values` with MPI-enabled pFUnit.

A parallel solution is provided in the form of the file [test_sum_all_rank_values.pf](./test_sum_all_rank_values.pf). This file
contains a pFUnit test module. To use this solution, copy this file into the test dir within the challenge dir.
